# AI-Based Predictive Maintenance for Industrial IoT 🏭

This is a machine learning web application that predicts the Remaining Useful Life (RUL) of industrial machinery using IoT sensor data (Temperature and Vibration). 

## Features
- Synthetic Data Generation for Machine Operations
- Scikit-Learn Random Forest Regression Model
- Interactive Web Interface using Streamlit
- Real-time Health Status & Maintenance Alerts

## How to Run Locally
1. Install requirements: `pip install -r requirements.txt`
2. Run the app: `streamlit run app.py`
